   Global features (2)
  - patch_major, patch_minor — which patch the game was played on

  Draft / context features
  - 10 champion IDs (one per slot, role-ordered: Top/Jg/Mid/Bot/Sup × Blue/Red)
  - 1 region ID

  Total inputs: 10 champion IDs + 1 region_id + 142 dense = 153 inputs

  Active unified model shape
  - Build 10 enriched player-slot tokens from champion, role, team, and that slot's history features
  - Inject shared global context from region and patch into every token
  - Run Transformer self-attention across all 10 tokens
  - Flatten the full encoded 10-slot board into multitask prediction heads

  Auxiliary training targets
  - win/loss
  - gold_diff
  - blue_dragons
  - red_dragons
  - game_length_minutes
